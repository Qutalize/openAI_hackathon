# 手話モデル選定

現在の追加動画検証は、ユーザー確認済みASL（米国手話）→英語を対象とする。

2026-09-12：動画07/08をUni-Sign・SpaMo・SSVP-SLTで推論し、同じ方法で精度・CLI処理時間・GPU使用量を比較した。
今回の2本ではUni-Signが原稿に最も近く最速、SpaMoがGPUメモリ最小。ただし全モデルで翻訳の誤りが残る。
[3モデル比較・全出力・計測条件・再現手順](reports/2026-09-12-pro-three-model-comparison.md)を参照。

1. 実演可能な言語と、単語認識/連続手話のどちらを試すかを確認する。
2. 重み、語彙、入力形式、利用条件が確認できる候補を選ぶ。
3. 試す候補に限り `<model_id>/` を追加し、READMEに出所と試運転手順をまとめる。
4. 動画1本で出力を確認し、その後に少数語と未知動作を試す。

モデル別の配置は [構成](../../docs/02-architecture.md)、既存調査は [モデル調査](../../docs/04-model-research.md) を参照。

汎用ジェスチャー認識を試す場合は、手話モデルとは別の用途であることを明記する。
